# Скрипты запуска Metalcard

Для нового сервера используется один сценарий:

```bash
cd /opt/metalcards
chmod +x scripts/bootstrap-production.sh
./scripts/bootstrap-production.sh --admin-email admin@metalcards.uz --admin-name "Metalcard Admin"
```

Сценарий:

1. проверяет `.env`, Docker Compose, SVG-принты, шрифты и изображения;
2. запускает PostgreSQL и сохраняет резервную копию в `.bootstrap-backups/`;
3. идемпотентно применяет актуальную схему `deploy/postgres/init/01_schema.sql`;
4. заполняет таблицы `designs` и `colors` из файлов и настроек текущего проекта;
5. безопасно запрашивает новый пароль администратора (пароль не попадает в историю команд);
6. собирает и запускает все контейнеры, затем показывает итоговые счетчики и состояние.

Повторный обычный запуск не перезаписывает изменения каталога, сделанные через админку. Чтобы намеренно вернуть названия и цены каталога к значениям из проекта, добавьте `--sync-existing`. Перед этим всё равно будет создан дамп.

Если учетная запись администратора уже настроена и менять ее не надо, используйте `--skip-admin`.

Стили, иконки, изображения и шрифты находятся в `frontend-next/public` и включаются в образ сайта во время сборки. SVG находятся в `frontend-next/origs`, подключаются к контейнерам как volume и регистрируются в таблице `designs` путем `/static/<категория>/<файл>.svg`. Скачивать эти файлы из интернета не требуется.
